# 🎀 미캔 "예쁘고 귀여움" 트랙 리서치 (2026-07 서치 저장본)

> 실사 스톡(밝은 화이트톤 한국형)과 **별개의 트랙**. 미캔에서는 귀여운 요소·템플릿이
> 아직 강하게 먹히므로, 요소(엘리먼트) 판매용 정보를 여기 보관한다.
> 판매 채널: 미리캔버스 **디자인허브** (기여자 로열티 누적형).

## 1. 핵심 발견 — 무엇이 팔리나

- **"잘 그린 그림"이 아니라 "단순하고 쉬운 그림"이 팔린다.** 실제 기여자 후기에서
  빨간 색연필 손글씨 PNG("NEXT" 문구 하나)가 꾸준히 판매된 사례. 퀄리티 경쟁이 아니라
  **실사용처 채우기 경쟁**이다.
- **손그림 느낌 일러스트 + 파스텔톤 조합**이 인기 주류. 귀여운 동물 캐릭터(강아지·토끼 등),
  밝고 경쾌한 캐릭터가 템플릿·요소 양쪽에서 강세.
- **사용처가 명확한 콘텐츠**가 승인율·사용률 모두 높다: PPT용, SNS 카드뉴스용,
  유튜브 썸네일용, 학급자료용.
- **심플한 배경이 은근히 인기** — 포스터·엽서·굿즈로 인쇄하는 수요 때문.
- 2026 컬러 트렌드는 파스텔 → **비비드 원색(레드·블루·그린·옐로) 회귀** 조짐.
  단, 미캔 주 수요층(교사·자영업·다꾸)은 여전히 파스텔+캐릭터 선호 → **파스텔 기본 + 비비드 포인트** 병행이 안전.

## 2. 확실한 수요처 (귀여움이 필수인 시장)

| 수요층 | 필요한 요소 | 시즌성 |
|---|---|---|
| 유치원·어린이집·초등 교사 | **칭찬스티커, 토퍼, 이름표, 알림장 꾸미기, 상장** | 3월 신학기·연말 최대 |
| 자영업(카페·공방·마켓) | 굿즈 스티커, 라벨, 가격표, 안내 카드 | 상시 |
| 다꾸·개인 굿즈 | 데코 스티커, 마스킹테이프풍 요소, 손글씨 | 상시 |
| SNS·블로그 운영자 | 카드뉴스 장식 요소, 말풍선, 구분선, 프레임 | 상시 |

시즌 키워드는 **미리 선점**해야 한다(검색 노출에 메타데이터 키워드가 직접 영향):
설날, 신학기, 어린이날, 여름방학, 추석, 핼러윈, 크리스마스, 졸업·입학.

## 3. 디자인허브 규격·정책 (실무 요건)

- **AI 생성 콘텐츠 허용** — 단, 업로드 시 **AI 생성 체크박스 표시 의무** (공식 헬프센터 규정).
- 템플릿 유형에는 AI 이미지·외부 클립아트 삽입 제한이 있으므로 **우리는 '요소(이미지·일러스트)' 등록이 안전 경로**.
- **해상도 2000px 이상** 권장 — 포스터·엽서·굿즈 인쇄 수요가 커서 고해상도 = 인쇄 수익.
  큰 사이즈일수록 단가·용도 상승 (배경류는 특히 크게).
- 요소는 **투명배경 PNG**가 활용도 최고 (스티커·토퍼·데코는 사실상 필수).
- 포트폴리오 심사 없음, 직접 제작물이면 누구나 기여자 등록 가능. 로열티는 사용·다운로드·인쇄 시 누적.
- 수익 현실: 후기 기준 월 수천 원~20만 원대 — **단일 홈런이 아니라 다작·누적형 시장**.
  하나의 스타일로 세트(12~30종)를 묶어 올리는 것이 유리.

## 4. 우리 파이프라인 적용 — "귀여움 트랙" 설계

실사 스톡 트랙과 분리해서 운영한다:

| | 실사 트랙 (기존) | 귀여움 트랙 (신규) |
|---|---|---|
| 스타일 | 밝은 화이트톤 실사 | 플랫 벡터풍·손그림풍·파스텔 캐릭터 |
| 산출물 | JPEG 장면 컷 | **투명배경 PNG 요소** (2000px+) |
| 단위 | 배치 20~60컷 | **세트 12~30종** (같은 스타일 통일) |
| 어도비 라우팅 | isAdobeEligible 적용 | **어도비 제외, 미캔 전용** (요소는 어도비 시장 아님) |

**프롬프트 스타일 가드 (귀여움 트랙 공통):**
`simple flat kawaii illustration, thick clean outline, pastel palette, plain white background
(isolated for easy cutout), sticker style, no text` + MJ는 `--no photo, realistic, texture, shadow`
— 배경 단색으로 뽑아 배경제거 → 투명 PNG 변환.

**첫 시안 후보 (시안 게이트: 세트당 1~3장 먼저):**
1. **칭찬스티커 동물 세트** — 파스텔 동물 12종 (교사 수요, 신학기 선점)
2. **가을·추석 토퍼 세트** — 송편·보름달·감·다람쥐 캐릭터 (시즌 임박, 기존 가을 배치와 키워드 시너지)
3. **손글씨풍 데코 문구 세트** — 참잘했어요·화이팅·오늘의할일 등 (단, 한글 텍스트는 AI 생성이 취약 → 후순위 또는 수기 제작)
4. **카드뉴스 장식 세트** — 말풍선·구분선·프레임 파스텔 12종 (상시 수요)

성과는 `signals.csv`에 동일하게 기록 (배치명 `cute-` 접두어, 형태 라벨 `요소형` 추가).
