# templates/ — 미리캔버스 템플릿 수익 라인

미캔 **템플릿 소득**(내 템플릿을 만들어 등록·판매)을 위한 데이터·기획 공간이다.
스톡 이미지(양산공장)가 "컷 한 장"을 파는 거라면, 여기는 "바로 쓰는 세트(템플릿)"를 만든다.

## 원칙 (지피티 검토 반영)

- **승인 = 수익 아님.** "최근 승인된 결"과 "오래 노출되는 결(스테디)"을 분리해서 본다.
  둘이 겹치는 요소가 "지금 만들어도 오래 갈 뼈대".
- **베끼지 않는다.** 승인작은 결(스타일 방향)만 참고. 레이아웃·에셋·문구는 독자 제작.
  분석기의 썸네일/페이지 저장은 내부 리서치용으로만.
- **낱장보다 가족.** 한 주제 = 카드뉴스+포스터+배너+SNS 정사각을 같은 디자인 언어로 묶은 세트.

## 폴더

| 폴더/파일 | 무엇 | 만드는 것 |
|---|---|---|
| `imports/` | 분석기 JSON 원본 보관 | `trend-intake` 스킬 |
| `trends.csv` | 컷·검색어별 신호 누적 (append-only) | `trend-intake` 스킬 |
| `reports/` | 주간 트렌드 리포트 (마크다운) | `trend-intake` 스킬 |
| `specs/` | 템플릿 기획 명세서 | `template-spec` 스킬 (2단계) |

## 흐름

```
미캔 분석기 (크롬, 로컬)
   → JSON 내보내기
   → [trend-intake 스킬] → trends.csv + 주간 리포트
   → 사람이 유망 주제 선택 + 레이아웃 눈으로 분해
   → [template-spec 스킬] → specs/<주제>.md 기획 명세
   → [stock-batch 스킬] → 명세에 맞는 부품(배경·PNG·배지) 생산
   → 미리캔버스에서 독자 템플릿 조립·등록
```

## trends.csv 신뢰 신호

RAW(원본 보존, 덮어쓰기 금지): 수집일 · 썸네일날짜 · 검색순위 · 페이지수 · 프리미엄 · 카테고리
버림: 색상/무드 자동 태그(부정확) · 판매량(도구가 못 잡음)
파생(규칙 계산, 재계산 가능): `노출후보플래그` · `신호라벨` · `신뢰도` · `판정규칙버전`

> ⚠️ 표기 원칙(GPT 지적): '썸네일날짜'는 승인일로 검증된 값이 아니라 날짜 신호,
> '순위'는 세션별 노출 순서다. 어디서도 승인·판매·스테디셀러로 단정하지 않고
> '노출 기반 후보'로만 부른다. 규칙이 바뀌면 `recompute.py`로 파생값만 재계산.
