# 어도비 업스케일 도구 (로컬)

GPT·미드저니로 뽑은 작은 그림을 **어도비 스톡이 받아주는 크기**로 키우는 내 컴퓨터용 도구.
양산공장·아뜰리에 형제 세트의 후처리 담당 — 그림 생성(GPT/MJ) → **업스케일(여기)** → 어도비 업로드.

## 왜 필요한가

- GPT 그림은 보통 **100만 화소(1024×1024)** → 어도비 최소선 **400만 화소(4MP)**에 미달
- 이 도구가 고품질(Lanczos)로 **약 450만 화소**까지 키우고 JPEG로 저장 → 어도비 통과
- **원본은 건드리지 않는다.** 결과는 `upscaled/` 폴더에 새로 생긴다.

## 쓰는 법 (가장 쉬운 순서)

### 준비 — 딱 한 번만
1. 파이썬이 없으면 설치: https://www.python.org/downloads/
   설치 화면에서 **"Add Python to PATH"** 체크를 꼭 켠다.

### 매번 — 이렇게
1. `upscale_adobe.py` 와 `어도비업스케일.bat` **두 파일을** 그림이 든 폴더에 복사한다.
   (예: `outputs\market-songpyeon-adobe-premium-05\adobe_ready\`)
2. `어도비업스케일.bat` 을 **더블클릭**한다.
3. 검은 창이 뜨고 자동으로 키운다. 끝나면 같은 폴더에 **`upscaled` 폴더**가 생긴다.
4. `upscaled` 폴더 안의 JPG를 어도비에 올린다.

> 폴더마다 두 파일 복사가 번거로우면, **PowerShell**로도 된다:
> 그림 폴더에서 **Shift + 마우스 우클릭 → "여기에 PowerShell 창 열기"** 누르고, 아래를 붙여넣기:
> ```
> python "C:\경로\upscale-tool\upscale_adobe.py" .
> ```
> (맨 끝의 `.` 은 "지금 이 폴더"라는 뜻)

## 어도비 기준 (참고)

| 항목 | 값 |
|---|---|
| 최소 화소 | 400만 (4MP) — 예: 2048×2048 = 419만 |
| 최대 화소 | 1억 (100MP) |
| 파일 형식 | JPEG |
| 파일 크기 | 45MB 이하 |

기준값을 바꾸려면 `upscale_adobe.py` 위쪽의 `TARGET_MP`(목표 화소)만 고치면 된다.

## 안 되는 것 / 주의

- 이건 **크기만 키운다.** 없던 디테일을 만들어내는 AI 업스케일(Real-ESRGAN 등)은 아니다.
  GPT 그림은 원래 깨끗해서 Lanczos만으로도 어도비 통과에 충분하다.
- 너무 작은 원본(예: 300px)을 4MP로 키우면 흐려질 수 있다. 이럴 땐 더 크게 다시 뽑는 게 낫다.
- 투명 PNG는 흰 배경에 합쳐 JPEG로 저장한다. (투명 요소는 어도비가 아니라 아뜰리에로 배경 제거)
