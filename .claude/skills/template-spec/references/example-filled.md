# 템플릿 기획 명세서 — 가을 카페 이벤트 홍보

> 작성일: 2026-08-03 · 출처 트렌드: trends.csv 2026-08-03 수집분
> ⚠️ 승인작은 결(방향)만 참고. 레이아웃·에셋·문구는 전부 독자 제작. 베끼지 않는다.

## 1. 기회 요약

- **수요 신호**: '가을세일' 검색 노출 순서 2위(프리미엄 100%) + '레트로'가 노출 기반 후보
  (썸네일날짜 5개월↑·순위 3위) → 가을 감성 + 오래 노출되는 정보구조가 겹치는 지점
  (※ 판매 증거가 아니라 공개 노출 신호)
- **시즌 타이밍**: 시즌 선점 — 9~10월 가을 시즌을 8월에 미리
- **바구니 분류**: 시즌 선점 40%

## 2. 다섯 가지 기록

| 축 | 내용 |
|---|---|
| **용도** | 가을 카페 신메뉴·이벤트 홍보 |
| **타깃** | 20~30대, 동네 카페·베이커리 사장 |
| **제목 영역** | 상단 30% 큰 제목 + 좌측 정렬, 손글씨 느낌 |
| **정보량** | 메뉴 3개 + 가격 + 이벤트 기간 + 매장 정보 |
| **색·분위기** | 크림 + 브라운 + 버건디 포인트, 아늑·따뜻 |

## 3. 레이아웃 패턴

```
상단 헤드라인 (가을 이벤트명, 큰 손글씨)
중앙 메뉴 사진 3칸 (동일 크기, 가격 배지 오버레이)
하단 기간·매장정보 바
```

- **바꾸는 것**: 메뉴 사진 3슬롯, 가격 텍스트, 이벤트명, 기간
- **고정하는 것**: 크림 배경톤, 제목 서체 위계, 3칸 그리드 여백

## 4. 기능 포인트

- [x] 사진 교체 슬롯: 3개
- [x] 가격/숫자 배지
- [x] 날짜·기간 필드
- [x] 비율 변형: 1:1(인스타), 4:5(카드), 세로(포스터)
- [x] 다중 페이지: 카드뉴스 5장 버전 별도

## 5. 템플릿 가족

| 형태 | 비율 | 용도 |
|---|---|---|
| 카드뉴스 5장 | 4:5 | 인스타 메뉴 소개 |
| 홍보 포스터 | 세로 | 매장 게시·창문 |
| 배너 | 가로 | 배달앱·웹 상단 |
| SNS 정사각 | 1:1 | 피드 단발 홍보 |
| 메뉴판 | 세로 | 테이블·계산대 |

## 6. 필요 생산물 (양산공장 부품 주문서)

|---|---|---|---|
| 가을 카페 배경(크림·브라운) | 사진 배경 | 6 | adobe/ |

## 7. 시리즈화

- **색상 변형**: 크림-브라운 / 버건디-베이지 / 머스타드-그린 3종
- **업종 변형**: 카페 / 베이커리 / 브런치 / 디저트 4종
- **비율 변형**: 1:1 / 4:5 / 세로
- 총 예상 원본 수: 3 × 4 × 3 = 36종
