# 토니(Tony) 카카오 움직이는 미니 이모티콘 — 상품 기획안

> 캐릭터: 사원증 목걸이를 건 아기 호랑이 "토니" (캐릭터 시트 기준)
> 목표: 카카오 이모티콘 스튜디오 **움직이는 미니 이모티콘** 승인 + 상업적 성공
> 근거 자료: 인기 미니 '와다다'(작가 관심 9.5만) 상품 구성, 손글씨 미니 '리액션 필수템' 목록, 카톡 리액션 픽커 UI

## 1. 미니 이모티콘만의 문법 (레퍼런스 분석)

인기 미니 상품을 뜯어보면 일반 이모티콘과 완전히 다른 문법이 보입니다:

1. **얼굴 클로즈업이 기본** — 180px에서 전신은 안 보임. 인기 미니 '와다다'는 35컷 중
   대부분이 얼굴(+손 약간)만으로 구성. 몸은 과감히 생략.
2. **캐릭터화된 오브젝트 컷이 필수** — 느낌표·물음표·경고장·아이스커피·전화·별·
   확성기·물방울 같은 사물에 캐릭터 얼굴을 이식한 컷이 패키지의 1/4가량.
   채팅에서 "기호처럼" 쓰이므로 사용 빈도가 높음.
3. **리액션 픽커 단독 사용** — 미니는 메시지에 찍는 리액션으로도 쓰임.
   즉 **맥락 없이 그 컷 하나만 봐도 의미가 통해야** 함.
4. **초단문 수요 목록** — 리액션 필수템 기준 고빈도 표현:
   넵! / 굿 / 대박 / 헐 / 엥 / 컹 / 흠 / 왜 / ㅋㅋㅋ / 좋아 / 최고 / 멋져 / 축 / 두근 / 땡!! / 콜 / 쫌
5. **저가 라인** — 미니는 200(초코) 수준의 낮은 진입장벽 → 취향 저격 + 사용 빈도로
   승부하는 상품. 한 컷 한 컷이 "매일 쓰게 되는가"가 곧 매출.

## 2. 그림체 결정 — "소프트 크레용 + 플랫 파스텔" (와다다형 단순화)

레퍼런스에 등장하는 후보 그림체 비교:

| 후보 | 특징 | 호랑이 적합성 |
|---|---|---|
| 원본 캐릭터 시트 그대로 | 풍성한 털 결, 그라데이션, 디테일 | ❌ 180px로 줄이면 털 디테일이 노이즈가 됨 |
| 낙서체 (오늘의짤·망그러진곰류) | 흐물흐물 라인, 흰 몸통, B급 감성 | ⚠️ 유행 강세지만 **줄무늬·주황색이 사라져 호랑이 정체성 소실** — 흰 곰·토끼와 구분 안 됨 |
| 카카오 기본 이모지형 | 노란 원형, 광택 | ❌ 캐릭터 IP가 안 남음 |
| **소프트 크레용 + 플랫 파스텔 (와다다형)** ✅ | 도톰한 부드러운 외곽선, 플랫 색, 볼터치 | ✅ **추천** |

**추천 근거 — 호랑이라는 캐릭터의 특성상:**
1. 호랑이 정체성은 **주황 바탕 + 검은 줄무늬 + 아이보리 머즐** 세 요소가 전부.
   플랫 스타일은 이 세 요소를 남기고 나머지를 다 버릴 수 있는 유일한 후보.
2. 줄무늬는 이마 3개 + 양볼 1~2개로 **단순화**해야 180px에서 무늬가 뭉개지지 않음.
3. 낙서체의 장점(말랑한 감성)은 **도톰한 크레용 질감 외곽선 + 볼터치**로 흡수 —
   낙서체까지 가지 않으면서 같은 귀여움을 확보.
4. 감정 폭발 컷(어흥·킹받네)에서 줄무늬가 살아 있어야 "순둥이 → 맹수" 갭이 작동.

**선호 스타일 반영 (빨간 동그라미 확인됨)** — 선택하신 4컷: 핑크 하트 2개 / 폭죽 /
라인아트 따봉 / 하트 도장. 공통점은 **얼굴이 아닌 오브젝트·심볼형 + 쨍한 비비드 컬러 +
볼드하고 단순한 벡터**. 이 취향을 다음과 같이 토니화해서 반영:

| 선호 컷 | 토니 버전 | 반영 위치 |
|---|---|---|
| 라인아트 따봉 | **호랑이 발 따봉** — 줄무늬 발 + 강조선, 얼굴 없이 발만 | #2 ㅇㅋ |
| 하트 도장 | **하트 발도장 쾅** — 발바닥 젤리가 하트 모양인 발도장 | #20 사랑해 |
| 핑크 하트 2개 | **줄무늬 하트 콤보** — 주황+검정 줄무늬 하트와 핑크 하트 | #16 |
| 폭죽 | 추카추카 컷에 비비드 색종이 강화 | #32 |

오브젝트 컷(C군)은 얼굴 컷보다 채도를 한 단계 올려 **비비드 포인트 컬러**(핑크 #FF5D7E,
옐로 #FFD34D)를 쓰는 것으로 톤 규칙 확정 — 리액션으로 찍혔을 때 기호처럼 또렷하게 보임.

## 3. 포지셔닝 & 컨셉

**"오피스 아기호랑이 토니 — 겉은 순둥, 리액션은 맹수"**

- 흰 셔츠 + 파란 사원증 = **직장인 정체성**. 트렌드 리포트 기준 30~40대 '직장인 공감'
  컨셉과 MZ '밈·신조어' 컨셉이 모두 상위권 — 토니는 둘 다 커버 가능.
- 갭 포인트: 평소엔 동글동글 → 감정 폭발 컷에서 호랑이 본색(어흥, 발톱).
- 타깃: 1순위 20~30대 직장인(업무 카톡·단톡), 2순위 10~20대 밈 사용층.

## 6. 이미지 생성 프롬프트

### 베이스 프롬프트 (컷 유형별 프리픽스)

**A. 얼굴 클로즈업용**
```
cute chibi baby tiger cub face close-up emoticon, big round fluffy head fills
the frame, orange fur #F5A623 with bold black tiger stripes, huge amber eyes,
cream white muzzle and cheeks, tiny paws near face, {표정}, thick soft
outlines, warm flat colors, kawaii messenger sticker, plain white background,
no text --niji 6 --ar 1:1 --s 120
```

**B. 포즈 컷용** — `face close-up` 대신 `full small chibi body, simple pose` + 흰 셔츠·사원증 명시

**C. 오브젝트 컷용** — 사물이 주인공: `{오브젝트} with cute tiger cub face, minimal simple icon-like sticker`

**일관성 유지**
- 캐릭터 시트를 MJ에 업로드 후 각 줄 끝에 `--cref <시트 URL> --cw 100` (v7은 `--oref`).
- **한글 문구는 프롬프트에 넣지 않기** (생성 모델 한글 깨짐 — stock-studio에서 한글
  렌더를 원천 차단한 것과 같은 이유). 문구는 후작업 벡터 타이포로.

### 컷별 프롬프트 35종

`prompts.txt`에 **midjourney-batch 즉시 투입 형식**으로 정리:

```bash
cd midjourney-batch
python mj_batch.py --prompts ../tony-mini-emoticon/prompts.txt --cookies cookies.txt
```

## 7. 애니메이션 제작 파이프라인

1. **키포즈 생성**: 컷당 시작·끝 2~3키포즈를 MJ로 생성 (프롬프트에 포즈 변형만 교체)
2. **정리**: 배경 제거, 팔레트 통일 (#F5A623 / #D97A16 / #1F1F1F / #FFE3B3)
3. **중간 프레임**: 클립스튜디오·Procreate Dreams에서 6~12프레임 보간.
   미니는 작으므로 **동작은 크게, 루프는 짧게** (0.5~1초 루프가 리액션 픽커에서 잘 보임)
4. **WebP 변환**:
   ```bash
   ffmpeg -framerate 12 -i frame_%02d.png -vf scale=180:180 -loop 0 -lossless 1 tony_01.webp
   ```
5. **검수**: 실제 카톡 다크모드(#1A1A1A) 위에서 확인 / 흰 테두리 2px /
   루프 이음새 / **리액션 크기(더 작음)로 축소해도 표정이 읽히는지**

## 8. 상품화 전략

**타이틀 후보**
1. **"오피스 아기호랑이 토니"** ← 추천 (타깃+캐릭터+이름 한 줄)
2. "리액션 맛집 토니"  3. "폼 미쳤다! 회사원 토니"

**대표컷**: 킹받네(9) 또는 퇴근(30) — 움직임 크고 공감 즉발.

**가격/수익 구조**: 미니는 저가(레퍼런스 기준 200초코) + 이모티콘 플러스 다운로드
수익 병행 → 개별 판매보다 **사용 빈도**가 수익의 핵심. 만능 리액션 16종이 그 엔진.

**시리즈 로드맵**
- 1탄 미니가 자리 잡으면 → 같은 컨셉 **일반 움직이는 이모티콘(360px 24종)**으로 확장
  (미니→일반 역방향 확장이 팬층 검증에 유리)
- 2탄: "토니의 연애티콘"(선물하기 수요), 3탄: "사장님 호랑이 vs 신입 토니"
- 시즌 한정: 설날(호랑이 IP 시너지 최강), 연말 송년회

**출시 타이밍**: 심사 2~4주 감안, 연초(갓생·중꺾마 시즌) 또는 명절 직전 제출.
