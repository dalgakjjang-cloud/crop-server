#F5A623 메인 #D97A16 음영 #FFE3B3 머즐 #33251A 라인 #1E88E5 사원증

1. 크기 검증 — 미니는 결국 "작아도 읽히는가"

같은 컷을 판매 페이지 크기(180px) → 채팅 크기 → 리액션 크기(32px)로 줄였을 때 줄무늬 3개·주황·머즐이 살아있는지 확인합니다.

2. 실사용 환경 목업 — 라이트 / 다크

카톡 라이트·다크 배경 위에서 스티커와 리액션 아이콘이 어떻게 보이는지. 다크모드 대비를 위해 외곽 흰 테두리를 적용했습니다.

3. 대표 모션 데모 6종

움직이는 미니의 핵심은 0.5~1초 무한 루프. 기획안의 모션 노트를 CSS로 재현했습니다.

4. 35종 전체 시안 그리드

얼굴 리액션 16 + 포즈 10 + 오브젝트 9 — '와다다'형 구성. ★ 표시는 상세페이지 대표컷 후보.

이 시안은 스타일·구성 승인용입니다. 실제 원화는 캐릭터 시트를 참조 이미지로 걸고 midjourney-batch에 tony-mini-emoticon/prompts.txt를 투입해 키포즈를 생성한 뒤, 보간·타이포 후작업 → 180×180 WebP로 마감합니다. 한글 문구는 전부 후작업 단계에서 얹습니다.
